# 电控串口模块交付要求

电控串口模块必须严格实现 [SERIAL_CONTROL_PROTOCOL.md](./SERIAL_CONTROL_PROTOCOL.md)，并满足以下验收项：

1. 使用独立逐字节解析状态机，能够处理分片、粘包、噪声和 CRC 错误并重新同步。
2. 所有命令先校验再 ACK；相同 SEQ 的重传不得导致动作重复执行。
3. 轨迹完整缓存后再执行；缺点、乱序、重复、时间不递增、越限或缓存不足必须拒绝。
4. `ROBOT_STATE` 中六轴位置来自真实编码器，并转换为约定的 J1～J6 关节坐标。
5. `MOTION_DONE` 和 `CLAW_RESULT` 使用相同 SEQ 重发，直到收到 ACK 或达到重试上限。
6. 自动控制期间 1 秒心跳超时必须受控停止并锁定故障；普通命令不能解除硬件急停。
7. UART 接收、协议解析和电机闭环分层，不在中断或解析函数里直接操作电机和继电器。
8. 提供解析错误、CRC 错误、重复帧、超时、轨迹拒绝和重传次数统计。
9. 提供可在 PC 上编译运行的协议单元测试，不依赖 STM32 外设。
10. 提交每轴方向、零点、减速比、编码器分辨率、软硬限位、最大速度和最大加速度参数表。
11. 夹爪按开环定时执行器实现：OPEN/CLOSE 启动非阻塞动作，约 1500 ms 后返回 `COMPLETED_UNVERIFIED`；不得根据碰撞信号报告抓取成功。
12. 夹爪不得传输或伪造开度、夹持力、压力和物体存在状态；PE13/PE9 必须互斥，急停和故障可立即中断动作。
