# 完整轨迹缓存串口部署说明

本工程通过 USART10 接收上位机发送的 AA55 v1 六轴轨迹。遥控器的档位判断、
`RC_CTRL/RC2_CTRL`、关节映射、软限位、初始化流程和原有 `dm_set_pos()` 均保持不变。

## 数据路径

```text
USART10 DMA -> AA55 解析 -> 完整轨迹缓存/校验/插值
             -> 同一拍六轴位置+速度快照
             -> HandTask 的视觉专用位置-速度输出
反馈关节角/速度 -> ROBOT_STATE -> USART10 DMA
```

视觉专用输出只在以下条件同时成立时启用：

1. 遥控器已经把控制模式切换到 `HAND_MODE_CUSTOM_CTRL`；
2. 串口轨迹模块已经生成有效的六轴目标快照；
3. 对应电机是 M4310 且处于位置环。

不满足任一条件时，HandTask 继续走原来的 `GENERAL_MOTOR_SET_OUTPUT()` 路径，
因此遥控和原有固定动作不会使用视觉速度缓存。

## 速度控制和保护

- 位置和速度由同一次轨迹插值一起写入临界区保护的快照，避免六轴或位置/速度半更新；
- 串口接收侧关节速度上限为
  `[0.42, 0.49, 0.49, 1.29, 1.50, 1.50] rad/s`；
- 电机侧仍保留原来的硬上限：1～3 号电机 `0.5 rad/s`，4～6 号电机 `3.0 rad/s`；
- 动态速度上限由轨迹速度和剩余位置误差计算，并始终裁剪到上述电机硬上限；
- 速度上限增大时有斜率限制，减小时立即生效，减少终点来回追赶；
- 活跃轨迹目标超过 20 ms 没有刷新时，HandTask 改为保持当前反馈位置、速度置零；
- 非法数值、无效映射或无效参数按最小保持速度失效保护；
- 方向仍由目标位置决定，发送给达妙位置-速度模式的速度字段始终为正的速度上限。

## 真机前必须确认

- 使用 Keil ARMCC5 完整编译并烧录本固件；PC 上的 GCC 单元测试不能替代固件编译；
- 机械臂悬空或卸载，在急停可触达的情况下先做单轴小角度测试；
- 依次回归 RC_CTRL、RC2_CTRL、夹爪手控和 CUSTOM 视觉模式；
- 记录六轴的目标速度、实际速度和最终位置误差，再决定是否调整跟踪增益；
- 当前工程没有可供适配器调用的独立 ESTOP 查询接口，本地急停必须继续独立生效；
- 轨迹加速度接收上限暂保留 `10 rad/s^2`，正常上位机配置仍限制为 `0.75 rad/s^2`。

PC 侧纯算法测试位于 `tests/test_visual_trajectory_speed.c`，不加入 H7 固件目标。
